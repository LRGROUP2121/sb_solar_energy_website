# SB Solar Energy Website

A modern, high-performance corporate website built for SB Solar Energy to showcase premium solar solutions for residential, corporate, industrial, and solar park applications.

## Features

- **Modern Glassmorphism UI**: High-end corporate aesthetic using Tailwind CSS with deep greens, amber accents, and slate dark modes.
- **Interactive Animations**: Advanced background animations, floating solar particles, and fluid page transitions powered by `framer-motion`.
- **Dynamic Routing**: Multi-page architecture built with `react-router-dom` ensuring instant loading between pages.
- **Global Contact Hooks**: Floating WhatsApp integration (`react-icons`) and prominent CTA banners to maximize customer conversion.
- **Component-Driven Architecture**: Fully modular React component structure strictly following ES6 arrow functions.

## Tech Stack

- **Framework**: React 18 with Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React & React Icons
- **Routing**: React Router DOM
- **Language**: TypeScript (TSX)

## Getting Started

1. Clone the repository
2. Run `npm install` to install dependencies
3. Run `npm run dev` to start the local development server on `localhost:5173`
